# mgesture 0.3.2

mgesture 0.3.2 fixes two real-world runtime gaps: Linux standalone packages now contain the dynamic Pynput input backends needed after onboarding, and the configured pause/resume shortcut now works in both the tutorial and normal runtime.

## ✨ Highlights

- Linux standalone X11 input works from the extracted release bundle.
- The configured global shortcut now pauses and resumes reliably.
- Final-package smoke tests exercise real platform input initialization without moving the mouse.

## ✨ New Features

None. This is a patch release.

## 🎓 First-run Experience

The tutorial now starts the same configured global shortcut listener used by normal runtime. The first shortcut press shows the paused state; the second resumes the tutorial. Practice input remains simulated, and Space remains the preview-only fallback.

## ⏯ Pause & Resume

The configured shortcut (`Ctrl+Alt+M` by default) is edge-triggered: one physical press produces one toggle, and key auto-repeat does not bounce between states. Toggle requests are processed independently of camera-frame delivery, and pausing still releases held input before the application resumes.

## 🐛 Bug Fixes

### Linux standalone input fix

The previous Linux standalone package could complete onboarding and then fail when normal X11 control started because Pynput selects its keyboard and mouse platform modules with runtime imports. The builder now includes the target-specific Pynput Xorg modules and utility modules, and the final extracted bundle smoke test loads them under an isolated Xvfb display.

### Reliable pause and resume

The tutorial previously displayed the configured shortcut but only handled its Space fallback. It now uses the same canonical Pynput `GlobalHotKeys` listener as normal runtime, queues control-plane toggles, reports listener failures clearly, and requires both pause and resume transitions before completing that step.

## 🛡 Safety & Reliability

- Tutorial and platform-input validation never dispatch real mouse actions.
- Pausing releases held buttons and resets transient gesture state; resuming waits for normal reacquisition semantics.
- `mgesture doctor` separates missing `DISPLAY`, XTest, xrandr, Pynput, and packaged dynamic-module failures.

## ⚡ Performance

No additional vision inference or runtime mouse-processing path was added. The shortcut callback only queues a small control-plane toggle, and normal runtime still uses one vision pipeline.

## 🖥 Platform Improvements

### Linux

Standalone X11 bundles include and exercise both Pynput Xorg keyboard and mouse backends under an isolated display during package smoke.

### macOS

Standalone builds include the target-specific Pynput Darwin keyboard and mouse backends and utility modules.

### Windows

Standalone builds include the target-specific Pynput Win32 keyboard and mouse backends and utility modules.

## 📦 Standalone & Distribution

The release retains six native standalone targets, native Mojo engines, the Python fallback, checksums, release manifests, SBOM, provenance attestation, malware scanning, and extracted-package smoke validation.

## 🔧 Changed

- PyInstaller packaging now owns an explicit target-aware Pynput backend policy instead of relying on runtime-import discovery alone.
- Packaged smoke invokes `self-test --platform-input` in addition to the fake-input gesture self-test.

## ⚠ Breaking Changes

None.

## ⬆ Upgrade

Linux/macOS:

```sh
curl -fsSL https://github.com/christiandoxa/mgesture/releases/latest/download/install.sh | sh
```

Windows:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://github.com/christiandoxa/mgesture/releases/latest/download/install.ps1 | iex"
```

Run:

```sh
mgesture
```

```sh
mgesture tutorial
mgesture doctor
```
