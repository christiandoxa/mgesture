# mgesture 0.3.1

mgesture 0.3.1 is a focused updater reliability patch. Standalone installations now use their bundled certificate trust store when checking GitHub release metadata, so explicit updates work in clean environments without relying on host certificate configuration.

## ✨ Highlights

- Reliable `mgesture update --check` in standalone bundles.
- Reliable `mgesture update` HTTPS metadata resolution in clean environments.
- Existing transactional update and six-target release validation remain enabled.

## ✨ New Features

None. This is a patch release.

## 🐛 Bug Fixes

- Fixed standalone updater metadata requests failing with certificate verification errors when the host system CA bundle was not discoverable.

## 🛡 Safety & Reliability

- HTTPS release metadata reads use the bundled `certifi` CA store when available and retain the existing manifest, checksum, architecture, staged self-test, and atomic activation checks.
- Failed updates continue to leave the current installation unchanged.

## ⚡ Performance

No runtime gesture or inference performance change.

## 🖥 Platform Improvements

### Linux

Standalone updater certificate resolution is more reliable in isolated Linux environments.

### macOS

Standalone updater certificate resolution is more reliable in isolated macOS environments.

### Windows

Standalone updater certificate resolution is more reliable in isolated Windows environments.

## 📦 Standalone & Distribution

The official release continues to publish six native standalone targets with native Mojo, Python fallback, checksums, manifest, SBOM, provenance, and malware scanning.

## 🔧 Changed

The updater uses the bundled Python certificate store for HTTPS metadata resolution when the `certifi` package is present.

## ⚠ Breaking Changes

None.

## ⬆ Upgrade

Linux/macOS:

```sh
curl -fsSL https://github.com/christiandoxa/mgesture/releases/latest/download/install.sh | sh
```

Windows:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://github.com/christiandoxa/mgesture/releases/latest/download/install.ps1 | iex"
```

Existing installations can use:

```sh
mgesture update
```
